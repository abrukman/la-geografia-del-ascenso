# La geografía del ascenso

Sitio estático dedicado exclusivamente al informe sobre fútbol argentino y federalización, con comparación con Brasil y Uruguay.

## Contenido
- `index.html`: edición íntegra navegable
- `informe.pdf`: edición de lectura descargable
- `LICENSE-CC0.txt`: declaración de licencia sobre el material original

## Publicación en GitHub Pages
1. Crear un repositorio público llamado `la-geografia-del-ascenso`.
2. Subir estos archivos en la raíz del repositorio.
3. Ir a **Settings → Pages**. Seleccionar **Deploy from a branch**, `main` y `/ (root)`; guardar.
4. Abrir la URL pública que GitHub confirme en la sección Pages, verificar bibliografía y descarga PDF.

No es necesario compilar ni instalar dependencias. El contenido HTML es autónomo y no envía datos a un servidor propio.
