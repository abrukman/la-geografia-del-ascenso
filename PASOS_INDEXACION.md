# Visibilidad orgánica de La geografía del ascenso

Esta edición conserva íntegro el contenido del informe y modifica solo sus metadatos HTML. Añade `sitemap.xml`, enlace canonical, Open Graph y metadatos para compartir el enlace.

## Actualización en GitHub

1. Abrí https://github.com/abrukman/la-geografia-del-ascenso
2. Elegí **Add file → Upload files** y arrastrá **index.html** y **sitemap.xml** de esta carpeta.
3. Confirmá la sobreescritura de index.html mediante el flujo de GitHub, o editá/reemplazá el archivo desde la interfaz si no se permite arrastrar un archivo existente. Conservá el nombre exacto y la raíz del repositorio.
4. Verificá que esté activo https://abrukman.github.io/la-geografia-del-ascenso/sitemap.xml

No hace falta volver a subir el PDF, salvo que desees actualizarlo. El `sitemap.xml` contiene **una sola URL** porque este sitio es un documento HTML con secciones internas.

## Indexación

Entrá en https://search.google.com/search-console/welcome e iniciá sesión con una cuenta Google. Agregá la propiedad de prefijo URL `https://abrukman.github.io/la-geografia-del-ascenso/`. Si la verificación no es automática, Google ofrecerá un archivo HTML de verificación o un método de metatag; ese archivo o etiqueta debe colocarse en el repositorio. Usá el menú **Inspección de URLs** para introducir la página principal y **Solicitar indexación** si corresponde. En **Sitemaps**, enviá `https://abrukman.github.io/la-geografia-del-ascenso/sitemap.xml`.

Opcionalmente, repetí el alta en https://www.bing.com/webmasters/ .
